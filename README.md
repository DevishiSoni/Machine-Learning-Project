# Machine-Learning-Project

Our project focuses on the “AvatarConnect - Multilingual 3D AI Avatars for Student Wellness” topic from the Lee Language Lab. We’d like to try and determine the efficacy of the AvatarConnect program at accurately determining the emotions being presented to the program by a user and how this varies/deteriorates based on the language that the user is interacting with the program in. To go about this, we would need to train a model to classify the emotions being displayed by a user. The data that we would need are sample messages that the program would receive from a user and our own classifications for what emotion is being displayed in each of the sample messages. As of right now, we’re thinking of using a Bayesian classification model to make predictions on new data. Multiple iterations are likely to be necessary to train a useful model as emotions can be a challenging classification to make with little information, even for humans at times.
